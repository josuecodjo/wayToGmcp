### Requirements

Install the following on your host:
- uv
- python3
- pip
- Anthropic API key

### Project

Clone the project and do the following

```
cd waytogmcp
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
source .venv/bin/activate

python lab1/app.py
```
